# Larpcord v0.1.10 — Clickable My Custom Hotfix

Start with the current Larpcord installation, upgrade to v0.1.10, then open **Edit Profiles**.

- [ ] Clicking **My Custom** opens one popup above the Profile Editor.
- [ ] The **×** close button responds to a mouse click.
- [ ] The **Banners**, **Nameplates**, **Decorations**, **Effects**, **Frames**, **Badges** and **Identity** tabs all respond on the first click.
- [ ] Badge family tabs respond; selecting a badge checks/unchecks it without closing the popup.
- [ ] You can click and type in Badge Search and both local name fields.
- [ ] The name field receives keyboard focus and saves local names.
- [ ] Click a Shop item: it becomes selected; the popup stays open.
- [ ] Escape closes the cosmetic picker without closing the entire Discord Profile Editor.
- [ ] Close and reopen the picker three times without freezes or stale overlays.
- [ ] Existing local badges, avatar decorations, profile frames and nameplates remain saved.
- [ ] Full Discord calls/messages, account data and untouched official Discord app continue working.

If any tab is still unclickable, send a screenshot of the entire popup and describe whether the close button works. Do not count this hotfix as passed based on the build alone.
